# Music Rating — контекст проекта (handoff для новой сессии)

Этот файл — выжимка всей истории разработки, чтобы новая сессия/модель
могла продолжить работу без потери контекста. Полный журнал по каждой
задаче — в `dev/worklog.md` (читать обязательно перед правками).

## 1. Что это за проект

Десктопное приложение **«Music Rating»**: личная музыкальная библиотека
(исполнители, альбомы, треклисты) с **совместным оцениванием** альбомов
несколькими участниками. Участники — зарегистрированные аккаунты.

- **Стек:** Python 3 + PySide6 (Qt6), тёмная минималистичная тема на QSS,
  локальная SQLite (`data/library.db`). Никаких веб-технологий.
- **Платформа пользователя:** Windows (`c:\Users\jorat\Documents\VS
  Projects\music-rating-app`). После каждой задачи пересобирается ZIP и
  пользователь распаковывает его себе.
- **Процесс:** пользователь даёт фичу/фидбек списком → реализация →
  автотесты + скриншоты → запись в `dev/worklog.md` → пересборка ZIP.
- Задачи 1–23 **выполнены и приняты**. Следующие кандидаты: облачная
  синхронизация (Supabase-проект уже создан) и/или P2P-оценивание в
  локальной сети (обсуждено, см. §8).

## 4. Данные (SQLite `data/library.db`)

- Каталог: `artists / albums / album_artists / album_tracks /
  track_artists / meta`.
- Пользователи: `users` (логин + соль/хэш пароля). **Участники
  оценивания = аккаунты** (STORE.raters).
- Оценки: у каждого альбома матрица `AlbumRatings` — `rater_names` +
  `values` (строки-треки × колонки-участники). Есть миграция со старого
  JSON (`_migrate_legacy_json`).
- Правила шкалы: 0–10 шаг 0.1; **«секретная 11»** — максимум одна у
  участника на альбом, в средних капится до 10 и подсвечивается
  акцентом; средняя по выставленным (None пропускаются); цвет оценки —
  `rating_color()` (<4 красный, <7 жёлтый, <9 зелёный, else синий).
- `STORE.change_password(user, new)` — БЕЗ текущего пароля; сменить
  пароль/имя **на актуальные нельзя** (отдельные ошибки: «Новый пароль
  совпадает с текущим», «Это уже ваше текущее имя»; смена только
  регистра имени допустима). `rename_user` обновляет имя во всех
  составах оценивавших.

## 5. Ключевые UI-соглашения (НЕ нарушать)

1. Все цвета/стили — только через `app/theme.py`. QSS — f-string: `{{ }}`.
2. **HoverButton** при ховере растёт на 10 % вокруг центра → у краёв
   контейнера обязателен запас (HOVER_PAD=10), иначе кнопка срезается.
3. Внутриприложные окна = полноэкранные оверлеи: блюр-снимок родителя
   (`_make_blurred`) + карточка `#dialogCard` (#1e1e1e, radius 16,
   подъём из низа за RISE_MS). Эталон — `exit_confirm_dialog.py`.
4. Глобальное правило `* { background-color: BG_MAIN }` красит ВСЕ bare
   QWidget. Любому контейнеру внутри `#dialogCard` нужен явный
   `background: transparent` (пример — `#profileStatusHolder`), иначе на
   карточке проступает тёмный прямоугольник #141414.
5. Оповещения вкладки «Настройки» профиля: держатель фиксированной
   высоты 24 px (появление текста не сдвигает поля), автоскрытие =
   3 с видно → **фейдаут 1.5 с**. Фейдаут — затухание альфы ЦВЕТА
   ТЕКСТА (`QVariantAnimation` + inline `color: rgba(...)`), **НЕ**
   QGraphicsOpacityEffect: карточка уже несёт свой эффект, вложенные
   эффекты Qt конфликтуют («Painter not active», мерцание).
6. Клик по вкладкам профиля идёт через `_select_tab` (гасит оповещения).
7. Иконки-кнопки (✕, галочки) — `IconToolButton` с рисованием линиями в
   paintEvent (не шрифтовые глифы).
8. Мастера (создание/оценивание) — QStackedWidget; Esc-каскад:
   подтверждение выхода → закрытие мастера.
9. Строка источника альбома: «Создано с помощью <лого Deezer>» (текст
   слева, лого справа) или «Создано вручную».
10. Кнопки: `#primaryButton`, `#ghostButton`, `#dangerButton` (крупная,
    только в подтверждениях), `#dangerSmallButton` (компактная), синяя
    `#rateNowButton` («Оценить?»).

## 9. Известные ловушки

- f-string QSS: фигурные скобки экранируются (`{{ }}`).
- QGraphicsOpacityEffect на детях карточки с эффектом — конфликт; для
  затуханий использовать альфу цвета текста.
- HoverButton у краёв — запас под рост, иначе «срезается».
- bare QWidget внутри #dialogCard — красится глобальным `*`; нужен
  transparent-стиль.
- В Linux-песочнице разработчика PySide6 требует LD_LIBRARY_PATH на
  распакованные Qt-библиотеки и offscreen-платформу (на Windows не нужно).
- `QShortcut` импортируется из `PySide6.QtGui` (из QtWidgets на новых
  версиях PySide6 — ImportError).
- QScrollArea: контент (setWidget) НЕ должен содержать родителя самого
  scroll — иначе бесконечный resize-цикл и «зависание» (Task 25,
  rooms_page). Распорку-«stretch» в списке при очистке сохранять
  (удалять только виджеты-строки).
- Сетевые сессии (Task 25): ключ `(album_id, is_host)` в
  `MainWindow._network_sessions`; `session.joined` — ВСЕ участники
  ВКЛЮЧАЯ хоста (хост первым); `open_for` сетевого мастера запрещён —
  только `open_for_session`; выход из мастера сессию НЕ снимает.
- Масштабирование Windows (ноутбук 125–150 %): `parent.grab()` возвращает
  pixmap в физических пикселях с DPR > 1. Единственная `_make_blurred`
  (эталон — `exit_confirm_dialog.py`) приводит всё к физическим пикселям
  (DPR=1), масштабирует радиус блюра ×DPR и возвращает DPR источника.
  НЕ плодить копии функции: все оверлеи импортируют её оттуда.
