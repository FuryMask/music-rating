ТЕСТОВАЯ СБОРКА MUSIC RATING
============================

Это тестовый билд для распространения. Отличия от dev-версии:

1. Пустая база: библиотека и аккаунты стартуют пустыми (демо-данные
   отключены). Наполнение появится после импорта базы через
   Профиль → «Настройки» → «Импортировать БД» (файл экспорта
   делается в dev-версии там же).

2. При запуске без залогиненного пользователя появляется окно
   «Внимание!» — нужно выбрать, кем вы являетесь (заглушки), либо
   «Меня здесь нет» (тогда откроется вход/регистрация). Выйти без
   выбора нельзя. Заглушка создаётся автоматически с паролем «1»
   и сразу логинится; имя и пароль можно менять в профиле.

3. Кнопка «По сети» при выборе режима оценивания неактивна
   («В разработке»).

4. Ключи Spotify встроены в код: НЕТ полей ввода ключей/прокси.
   ВАЖНО: впиши свои Client ID / Client Secret (и, если нужно,
   прокси) в файл app/build_config.py — сейчас там пустые заглушки,
   без них ссылки на Spotify покажут ошибку (Deezer и YouTube Music
   работают без ключей).

Файл-конфиг сборки: app/build_config.py (заглушки, пароль заглушек,
тексты предупреждения, ключи Spotify).
